# 📊 Panorama Insta – Analytics e Radar de Tendências

Ferramenta de demonstração para análise de perfis do Instagram, criadores de conteúdo, lojas e negócios. Insira um @usuário ou link e obtenha um painel completo com métricas de seguidores, engajamento, Reels, Stories, dados demográficos e um radar de tendências.

## ⚡ Tecnologias
- HTML5, CSS3 (design responsivo e modo escuro)
- JavaScript puro
- [Chart.js](https://www.chartjs.org/) para gráficos

## 🚀 Como executar
1. Clone este repositório.
2. Abra o arquivo `index.html` em qualquer navegador.
3. Para publicar online, ative o **GitHub Pages** nas configurações do repositório.

## 🔍 Funcionalidades
- **Panorama atual:** seguidores, impressões, engajamento, alcance.
- **Demografia:** gênero e faixa etária do público.
- **Conteúdo:** top posts (feed + Reels), visualizações.
- **Horários nobres:** picos de atividade semanal.
- **Tendências:** hashtags e áudios virais.
- **Concorrência:** adicione perfis para comparar métricas (simulado).

## ⚠️ Aviso
Esta versão utiliza **dados simulados**. Para conectar aos dados reais do Instagram, é necessário integrar a [Instagram Graph API](https://developers.facebook.com/docs/instagram-api) com um backend próprio.

Desenvolvido como material educacional e de protótipo.
